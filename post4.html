Hola, en este post quiero hablarles sobre ARES-32, ARES-32 es un dispositivo inspirado en dispositivos como el Flipper Zero y Bruce la idea es que puedas hacer reconocimiento basico y algunos ataques desde un dispositivo que cabe en la palma de tu mano y que no cuesta mas de 300 o 400 pesos mexicanos, este es un proyecto que llevo planeando desde hace unos años cuando salio el Flipper Zero, actualmente el proyecto aun se encuentra en desarrollo durante el cual he aprendido muchas cosas de las que hablare en posteriores posts, el proyecto tiene el objetivo de ser modular, es decir que despues puedas agregar cosas como RF o NFC sin tener que reescribir todo el codigo, es por eso que decidi crear un "sistema operativo" y sobre el hacer las aplicaciones, hasta el momento el sistema cuenta con un sistema de UI, un sistema que se encarga de manejar los pines GPIO y uno que se encarga de manejar el WIFI, en cuanto a aplicaciones, hasta el momento tiene un Monitor GPIO para poder saber de que pin vienen las señales y un Escaner de redes WIFI que te muestra las redes del entorno, posteriormente quiero agregar un modulo para hacer ataques de Evil Twin, Ataques simulando dispositivos HID, Deauther, y quiero empezar a probar cosas con Bluetooth.
